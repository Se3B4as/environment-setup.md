Cybersecurity Home Lab!!

## 📌 About This Project

Welcome to my Cybersecurity Home Lab!

This repository documents my hands-on journey in cybersecurity through a self-hosted lab environment built with two physical computers.

The main goal is to develop practical skills in network security, Windows administration, security monitoring, vulnerability assessment, and incident response.

This lab will be used to simulate real-world scenarios, perform security experiments, document technical challenges, and develop practical cybersecurity knowledge.

## 🖥️ Lab Infrastructure

The Home Lab consists of two physical computers connected to the same local network.

### PC 1 – Main Machine
- **CPU:** AMD Ryzen 5 5500
- **RAM:** 16 GB
- **Storage:** NVMe SSD
- **Operating System:** Windows 11 Home
- **Network Connection:** Ethernet (Wired)

### PC 2 – Secondary Machine
- **CPU:** AMD Ryzen 5 5500
- **RAM:** 16 GB
- **Storage:** SATA SSD
- **Operating System:** Windows 11 Home
- **Network Connection:** Wi-Fi

### Network Environment
- **Network:** Same local network
- **Router:** Shared network infrastructure
- **Connectivity:** Ethernet and Wi-Fi

Both machines are connected to the same local network.
